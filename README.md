# XenBlocks Miner by Tony.x1

Modular **Python + native CUDA** miner for [XenBlocks](https://xenblocks.io).

Pick your platform — docs are split so Windows and Linux don’t mix:

| Platform | README | HOWTO |
|----------|--------|--------|
| **Windows** | [README-Windows.md](README-Windows.md) | [HOWTO-Windows.md](HOWTO-Windows.md) |
| **Linux** | [README-Linux.md](README-Linux.md) | [HOWTO-Linux.md](HOWTO-Linux.md) |

| | Windows | Linux |
|--|---------|--------|
| **Start** | `Start-Miner.bat` | `./start-miner.sh` |
| **CUDA lib** | `xen_cuda.dll` | `libxen_cuda.so` |
| **Build** | `.\native\build.ps1` | `./native/build.sh` |
